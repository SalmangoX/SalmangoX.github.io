月账本Monthly Ledger · 0.24 测试版

装在手机主屏幕上的个人记账网页 App：按月记录收支和资产，按季度、按年查看统计，并长期追踪「独秀指数」。没有服务器，数据默认只在你自己的设备上。

打开月账本 安装到主屏幕
Features

功能

两种记账方式

月账本：每月填一次总数（收入、支出、能力收入、月底存款和欠款）。单笔账本：逐笔记录，可批量录入、自定义分类，自动汇总到月账本。

月 / 季 / 年统计

结余、储蓄率和净资产；本季度至今、今年至今的累计；和上月、去年同月对比。

独秀指数走势

记录每个月的独秀指数，可左右滑动的长期走势图，加年度明细表。

多账本

新建多个账本并自定义名称，各账本的数据互不影响。

手写签名

横屏手写板，带钢笔笔锋，可调粗细；签名显示在首页卡片右上角，可存为方案一键套用到所有账本。

顺手的输入

自带数字键盘，支持从剪贴板粘贴金额，下滑收起；日期和月份用表格或滚轮选。

Duxiu Index
独秀指数 = 能力收入（月） ÷ 理想生活成本（月）

能力收入是靠自己能力挣到的钱，比如工资、兼职、副业；理想生活成本是过上想要的生活每月需要多少钱，可以随时修改，从生效月份起计算。指数 ≥ 1，说明靠自己的能力已经能撑起理想生活。灵感来自一位 YouTube 创作者。

Install

安装到主屏幕

月账本是网页 App，不用去应用商店。在 App 菜单里点「安装到主屏幕」，装好后从主屏幕图标打开，没有网络也能用。

安卓 Chrome / Edge、电脑 Chrome / Edge点按钮后在系统弹窗里确认「安装」
iPhone / iPad（Safari、Chrome）按 App 里的图文引导：分享 → 添加到主屏幕
Mac Safari菜单栏「文件」→「添加到程序坞」

从主屏幕图标打开和在浏览器标签页里打开，数据是分开保存的。

Privacy

数据与同步

只在你的设备上

没有服务器，不收集任何信息。仓库公开的只有程序代码，不包含任何人的记账数据。

导出备份

菜单 →「导出备份」把所有账本导出成一个文件。换手机或清理浏览器数据前请先备份。

加密多设备同步（可选）

先用你设的同步密码加密，再存进你自己 GitHub 账号下的私密 Gist，连 GitHub 也看不到内容。忘了密码云端就无法解密。

界面支持浅色、深色、跟随系统；语言支持简体中文、繁體中文、English、日本語。当前为测试版，功能和数据格式仍可能调整。
