月账本Monthly Ledger · 0.24 测试版

装在主屏幕上的记账本：每月记一笔总账，或者一笔一笔记；看结余、储蓄率和独秀指数怎么变。没有服务器，数据只在你自己手里。

打开月账本 安装到主屏幕
Features

功能

两种记账方式

每月记一次总数，或一笔一笔记、自动汇总

月 / 季 / 年统计

结余、储蓄率、净资产，和上月、去年比

独秀指数

≥ 1，说明靠自己就撑得起想要的生活

灵感来自一位 YouTube 创作者

多个账本

日常、旅行、副业，互不影响

手写签名

横屏手写，带钢笔笔锋

顺手的输入

自带数字键盘，金额可以直接粘贴

离线可用

装到主屏幕，没网也能记

数据只在你手里

没有服务器；可选加密同步到你自己的 GitHub，换手机前导出备份

浅色 / 深色 / 跟随系统；简体中文、繁體中文、English、日本語。当前为 0.24 测试版，功能和数据格式仍可能调整。

Install

装到主屏幕

月账本是网页 App，不用去应用商店；装好后从主屏幕图标打开，没有网络也能用。

其他设备

从主屏幕图标打开和在浏览器标签页里打开，数据是分开保存的。
