节律 Cadence1.4.2

带优先级颜色的日历

年 / 月 / 周视图、今日页、课表、记录日历和纪念日历，放在同一个应用里。一份数据，四个平台互通。

  • 四档优先级按色彩心理配色：灰 · 天蓝 · 琥珀 · 朱红
  • 课表可从表格、网页或照片识别导入，按科目自动配色
  • 记录日历带等级评分和统计热力图，纪念日可生成分享图
  • 用自己的 GitHub Gist / WebDAV / iCloud 云盘同步

月账本0.24 测试版

每月收支、资产与独秀指数

装在手机主屏幕上的记账网页 App。按月记录收支和资产，按季度、按年看统计，长期追踪「独秀指数」。

  • 月账本填总数，或逐笔记账自动汇总
  • 结余、储蓄率、净资产，对比上月和去年同月
  • 独秀指数 = 能力收入 ÷ 理想生活成本
  • 离线可用；可选加密同步到你自己的私密 Gist
